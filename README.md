# АІС бухгалтерського обліку малого підприємства

Десктопний застосунок для ведення внутрішнього бухгалтерського обліку малого підприємства, контролю фінансових потоків та взаєморозрахунків між контрагентами. Розроблений у межах курсового проєкту з дисципліни «Проєктування автоматизованих інформаційних систем».

---

## Основні можливості

* **Управління контрагентами:** створення, перегляд, редагування та видалення контрагентів із зазначенням найменування, локації (адреси/приміток) та автоматичним створенням прив'язаного рахунку (`Safe`) із нульовим початковим балансом.
* **Журнал грошових транзакцій:** фіксація транзакцій між обраним активним контрагентом та іншими учасниками системи із додаванням коментарів та автоматичним логуванням дати створення й останнього редагування.
* **Автоматичний перерахунок балансів:** під час створення, зміни або видалення транзакції система автоматично перераховує баланси рахунків відправника та отримувача.
* **Фільтрація операцій:** вибірка транзакцій для конкретного активного контрагента за вказаним часовим діапазоном (`Start Date` — `End Date`).
* **Автономність:** локальне збереження даних у файлі SQLite без необхідності розгортання зовнішнього сервера баз даних.

* **Платформа та мова:** .NET 9, C#
* **Графічний інтерфейс (UI):** Windows Presentation Foundation (WPF), XAML
* **База даних:** SQLite (`UserData.db`)
* **Середовище розробки:** Microsoft Visual Studio

## Структура проєкту та архітектура

Проєкт побудований у просторі імен `Store` та поділений на логічні компоненти:

* **Точка входу:**
  * `App.cs` — ініціалізація конфігурації підключення до `UserData.db`, перевірка та автоматичне створення схеми БД (`EnsureCreated()`), запуск головного вікна.
* **Моделі даних та контекст БД:**
  * `Contragent` — сутність контрагента (`Id`, `Name`, `Location`, `Account`).
  * `Safe` — рахунок (`Id`, `Amount`), пов'язаний з контрагентом зв'язком "один до одного".
  * `Transaction` — сутність фінансової операції (`Id`, `CreationDateTime`, `RedactionDateTime`, `Amount`, `Giver`, `Reciever`, `Comment`).
  * `DataContext` — контекст бази даних EF Core для керування таблицями `Contragents`, `Safes`, `Transactions`.
* **Інтерфейс користувача:**
  * `Main.xaml` / `Main.xaml.cs` — головне вікно з панеллю перемикання режимів (`Contragents` / `Transactions`), вибором активного контрагента, кнопками дій (`Add`, `Edit`, `Delete`) та динамічною робочою областю (`DataGrid` і форми введення).
  * `FilterWindow.xaml` / `FilterWindow.xaml.cs` — діалогове вікно налаштування часових меж фільтрації транзакцій.

## Схема бази даних

База даних SQLite (`UserData.db`) створюється автоматично при першому запуску застосунку та складається з трьох таблиць:

| Таблиця | Поля | Опис |
| :--- | :--- | :--- |
| **`Contragents`** | `Id` (PK), `Name`, `Location`, `AccountId` (FK) | Інформація про контрагентів системи |
| **`Safes`** | `Id` (PK), `Amount` | Баланси рахунків контрагентів (зв'язок `1:1` з `Contragents`) |
| **`Transactions`** | `Id` (PK), `CreationDateTime`, `RedactionDateTime`, `Amount`, `Comment`, `GiverId` (FK), `RecieverId` (FK) | Історія фінансових операцій між відправником та отримувачем |

## Запуск та використання

### Вимоги
* ОС Windows 10 / 11
* [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0) (або .NET 9 SDK для збірки з вихідного коду)

### Запуск зі скомпільованої версії
1. Встановіть застосунок за допомогою інсталятора `Setup.exe` розпакованого з файлу Install.zip.
2. Запустіть `Application.exe`.
